Before you start
  • Run npm start to save everything on the local server. Without it, each app keeps its data in your browser instead, and the apps still work.
  • Each app starts with sample data. Use Settings → Restore demo data to reset it at any time.
  • The Claude options in DocPilot and Ledgerly are optional. Add your own API key in Settings to enable them; without a key both apps still work.
